# The-internet-heroku-app-solved
Automated testing framework for Java applications using TestNG, Cucumber, and Allure reporting. Fully integrated with Maven and Heroku for CI/CD deployment

## Java Unit Test Framework

A robust, scalable Java-based testing framework designed for backend and UI test automation. Built with:

- **TestNG** for test execution
- **Cucumber** for BDD-style test definitions
- **Allure** for rich, interactive test reports
- **Aquality Selenium** for UI automation
- **Awaitility** for asynchronous waits
- **Gson** for JSON handling
- **Lombok** for clean, boilerplate-free code

### Features

- Behavior-driven development (BDD) test definitions with Cucumber
- Rich test reporting with Allure
- Modular and extensible test structure
- Compatible with Java 17 and Maven
- Deployable and runnable in CI/CD environments like **Heroku**
- Supports Page Object Model for UI automation via Aquality

### Technologies Used

- Java 17
- Maven
- IntelliJ IDEA
- Heroku (deployment)
